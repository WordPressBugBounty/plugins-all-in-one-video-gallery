**All-in-One Video Gallery** is a video posts plugin that lets you add videos as posts and build scalable, searchable, SEO-optimized video galleries in minutes — no coding required.

Whether you need a single embedded video player or a full video-sharing website like YouTube or Vimeo, this plugin covers it. Suitable for course creators, video bloggers, podcasters, businesses, and anyone embedding video on WordPress.

### PLAYER FEATURES

* A Custom HTML5 Video Player that supports **MP4**, **WebM**, **OGV**, **HLS**, **MPEG-DASH**, and embeddable players like **YouTube**, **Vimeo**, **Dailymotion**, **Rumble**, **Facebook**, **Bunny Stream** and more.
* **Player Controls:** play/pause buttons, timer, progress bar, duration, speed control, quality switcher, volume button, picture-in-picture button, fullscreen button, share buttons, embed button, download button, subtitles on/off, keyboard hotkeys
* **Playback Options:** autoplay, loop, muted, preload, playsinline
* Subtitles & Captions (WebVTT).
* Chapter Markers.
* GDPR compatibility.
* [+] support embed code from any third-party video sharing websites.

### DEVELOPER OPTIONS

The videos (aiovg_videos) belong to a WordPress Custom Post Type. Similarly, the categories (aiovg_categories) and tags (aiovg_tags) belong to the WordPress Custom Taxonomy. The plugin doesn't use any custom tables and the settings are stored in the WP_Options table using the WordPress SETTINGS API. In short, the plugin has been developed completely using the WordPress CORE features. So, if you're a WordPress developer, you can customize/extend the plugin as you like using the WordPress hooks system easily.

Similarly, the front-end gallery layouts added by our plugin can be customized by developing or overriding our existing templates. Please [check for a detailed documentation](https://plugins360.com/all-in-one-video-gallery/child-themes-and-templates/) on this.

== Installation ==

1. Download the plugin.
2. From the WordPress Admin Panel, click on Plugins => Add New.
3. Click on Upload, so you can directly upload your plugin zip file.
4. Use the browse button to select the plugin zip file that was downloaded, and then click on Install Now.
5. Once installed, click "Activate".

== Frequently Asked Questions ==

= 1. I have installed the plugin. How to build my first Gallery? =
Thanks for installing our plugin. The plugin dashboard should have all the necessary instructions required to build a gallery. Simply follow that.

For more detailed instructions visit our plugin [documentation](https://plugins360.com/all-in-one-video-gallery/documentation/).

Still, Having Issues? We are just an email away. Please write to us describing your issue using the "Contact" form available under our plugin's menu. You should receive a reply within 24 hours (except Sunday).

= 2. Can I show my videos in a popup, slider, playlist, or something more engaging? =
Yes, you can. Kindly refer to the instructions below,

1. [Popup](https://plugins360.com/all-in-one-video-gallery/popup/)
2. [Inline](https://plugins360.com/all-in-one-video-gallery/inline/)
3. [Slider](https://plugins360.com/all-in-one-video-gallery/slider/)

= 3. Can I upload large video files using this plugin? =
Sure, the plugin doesn't apply any restriction on the uploaded file size. If you're not able to upload large files, then it must be your server configuration that is not suitable for large file uploads. Simply write to your HOST and ask them to increase the upload file size limit.

= 4. Does the plugin support third-party page builders like "Elementor", "WPBakery", "Divi", etc.? =
Yes. Simply, generate your shortcode using the plugin's "Shortcode Builder" and add it to your favorite page builder.

= 5. Does this plugin work with the Gutenberg block editor? =
Yes. All-in-One Video Gallery includes native Gutenberg blocks for video galleries, single video players, video categories, and the search form. You can build your gallery layout directly inside the block editor without writing any shortcode.

= 6. Is the plugin compatible with WordPress Multisite? =
Yes, it is. However, do not "network-activate" the plugin. Activate it only on the subsites on which you need the gallery. This can be done under "Plugins => Add New" as the Administrator user.

= 7. The download button in the plugin is not working. =
The download option works only on the "Self Hosted / External URL" source type. Even if the video is self-hosted, the video file must be publicly accessible to download. So, make sure that your file is publicly accessible.

Also, the videos from third-party services like "YouTube", "Vimeo", "Dailymotion", or "Rumble" cannot be downloaded.

= 8. How do I embed a YouTube playlist or channel in WordPress? =
You can embed individual YouTube videos using the plugin's video editor — paste the YouTube URL and the plugin handles the rest. For automatic YouTube channel or playlist imports (fetching new videos on a schedule), upgrade to the Premium version which includes the Video Automations feature.

= 9. Does this plugin support HLS or MPEG-DASH adaptive streaming? =
Yes. The built-in HTML5 video player supports HLS (`.m3u8`) and MPEG-DASH (`.mpd`) streams in addition to standard MP4, WebM, and OGV files. Simply paste your streaming URL as the video source.

= 10. Can I restrict videos so only logged-in users can watch them? =
Yes. The plugin includes a video access control system that lets you restrict videos globally or per video. You can allow all visitors, logged-in users only, logged-out users only, or specific user roles. A trailer/teaser clip can also be shown to users who do not have access.

= 11. Does this plugin support subtitles and closed captions? =
Yes. You can upload WebVTT (`.vtt`) subtitle tracks for your self-hosted videos and configure the default language. Multiple subtitle tracks are supported on a single video.

= 12. Is the plugin compatible with Paid Memberships Pro? =
Yes. Install Paid Memberships Pro and its [Custom Post Type Membership Access](https://www.paidmembershipspro.com/add-ons/custom-post-type-membership-access/) add-on, select "aiovg_videos" under "Memberships => CPT Access", and then use the "Require Membership" box on any video to choose which membership levels can watch it.

Visitors without a required level see the Paid Memberships Pro membership message in place of the video, wherever it appears: single video pages, shortcodes, blocks, widgets, and popups. If the video has a trailer, they see the trailer instead. Administrators without a level see the same message; use the admin bar's "View" menu to preview the member and non-member views.

This protects the player, not the video file itself: anyone who already has a self-hosted file's URL can still open it. For stronger protection, use Bunny Stream with token authentication, or Paid Memberships Pro's own file protection.

= 13. Where do I report security bugs found in this plugin? =
Please report security bugs found in the source code of the All-in-One Video Gallery plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/f6cdb560-024c-4cbc-8f6b-c1d4f1ee54e0). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.

= 4.9.2 =

* Security Fix: Two bypasses of the Server-Side Request Forgery protection added in 4.9.0 for the video download ('vdl') feature. A download URL on the site's own hostname but a different port skipped the address check entirely, and a hostname could resolve to a permitted address during validation and a different one when the file was actually fetched (DNS rebinding). The site's own web ports are now the only ones treated as its own server, and each download request is sent to the exact address that was validated. Both issues were discovered and reported responsibly to us by [Mohammed Abd Alrahman](https://mohmadev.com/).
* New: Premium Automations — added an optional "Published After" date field to the import source settings (YouTube and Vimeo). Videos published before this date are skipped during the import, so an automation can pick up only new content going forward instead of crawling the source's entire back catalog. Leave the field empty for the previous behavior. For YouTube channel imports, the plugin also stops requesting further API pages once it reaches videos older than the date, and for YouTube search imports the date is passed natively to the YouTube API — both reducing your API quota usage.
* New: Premium Automations — added the `aiovg_import_video` developer filter, applied to each video just before it is imported. Modify the video object (title, description, image, and more) or return false to skip the video entirely; skipped videos are counted as "Excluded" in the Import Log. Applies to both YouTube and Vimeo imports, and is reflected on the Preview Import screen.
* New: Premium Automations — added the `aiovg_can_import_video` developer filter (return true to allow re-importing a video that already exists on the site), replacing the legacy `can_import_video` hook, which remains supported for backward compatibility.
* Tweak: Updated Freemius SDK to version 2.13.4.
* Fix: Premium Automations — when videos were imported as drafts with the "keep the original published date" option enabled, the imported date was lost on publish and reset to the current time. Draft posts now retain the original YouTube/Vimeo publish date when they are published.
* Fix: Premium Automations could occasionally create duplicate video posts when two import runs for the same source (YouTube or Vimeo) overlapped, e.g. when WP-Cron spawned concurrent requests. Each automation now takes an import lock before it runs, with automatic recovery if a run crashes before finishing, so an overlapping run is rescheduled instead of racing the one already in progress. Separate automations are unaffected and still import independently.
* Fix: Restored the close button on the Premium Popup and Slider gallery templates' video lightbox, based on customer feedback, after it was inadvertently removed in a previous version.
* Fix: Self-hosted videos linked from Dropbox (www.dropbox.com share links) would fail to seek and eventually stop playing in Firefox, due to Dropbox's download links redirecting to temporary, rate-limited URLs. Dropbox URLs are now automatically converted to their direct-streaming format (dl.dropboxusercontent.com) at playback time, so existing videos keep working without any manual changes.
* Fix: Various performance and security improvements.
